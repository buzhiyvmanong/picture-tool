# Picture Tool

一个低内存优先的 Windows 截图、标注、贴图工具原型。

## 技术路线

- UI 框架：WPF
- 语言：C#
- 运行目标：Windows 桌面
- 常驻模式：托盘 + 全局快捷键
- 图片策略：大图落临时文件，避免在窗口间传 base64
- 标注策略：保存矢量命令，导出时再合成

## 默认快捷键

- 截图：`Ctrl + Shift + A`
- 贴图：`Ctrl + Shift + V`

主窗口和托盘菜单都提供“快捷键设置”入口。配置会保存到：

```text
%APPDATA%\PictureTool\settings.json
```

## 使用方式

- 启动后默认常驻托盘。
- 双击托盘图标可以打开主面板。
- 主窗口右上角关闭只会隐藏到托盘。
- 托盘菜单可以显示所有贴图、关闭所有贴图、退出程序。

## 截图和滚动截图

点击主面板、托盘菜单或快捷键触发“截图”后，先用鼠标拉出截图起始区域。

普通截图：

- 框选后进入原地标注。
- 工具条里可以画笔、矩形、文字、马赛克、橡皮擦、保存、复制和贴图。

滚动截图：

- 框选起始区域后，点击工具条里的剪刀图标进入滚动截图。
- 进入后会先截取当前这一屏，蓝色选区继续保留为滚动区域。
- 选区旁边会显示已经累计拼好的长图预览。
- 实际长图会自动避开选框最外侧边缘，防止蓝色选区线被拼进图片。
- 点击 `自动滚动` 后，工具会持续慢速向下滚动并拼接。
- 滚动过程中再次点击同一个按钮会暂停，暂停后按钮会变成 `继续滚动`。
- 自动滚动会按固定慢速执行；只有确认新画面和上一段连续时才会追加到长图。
- 自动滚动使用受控拼接判定，遇到重复内容时不会因为多个相似重叠点就提前停止。
- 自动滚动如果无法确认连续，会停在已经安全拼好的位置，不会把断开的内容拼进最终图片。
- 确认无误后点击 `确定`，图片会自动复制到剪贴板。
- 也可以点击 `保存` 导出 PNG，或点击 `A` 进入标注窗口继续编辑。
- 工具会校验相邻两段是否有足够重叠；只有手动滚动过快导致不连贯时，才会提示“滚动速度过快，请重新回到截图位置，缓慢滑动”。

## 内存占用

常驻使用建议运行 Release 版本：

```powershell
dotnet build .\src\PictureTool\PictureTool.csproj -c Release
.\src\PictureTool\bin\Release\net10.0-windows\PictureTool.exe
```

程序空闲后会自动整理未使用的大图内存。截图、滚动截图、标注和贴图时会短暂占用更多内存，窗口关闭后会再次回收。

## 标注工具

普通截图框选后会进入原地编辑：

- 支持移动、矩形、圆形、直线、箭头、画笔、文字、马赛克、高亮、序号、橡皮擦、撤销、复制、保存、贴到屏幕。
- 点击画笔、形状、箭头等工具后会显示二级工具条，可以选择颜色和粗细。
- 点击文字工具后会显示二级工具条，可以选择颜色和字号。
- 已添加的文字再次点击可以编辑；清空文字后确认会删除这个文本框。
- 橡皮擦会擦除碰到的画笔笔迹和马赛克对象，不会删除文字。

快捷键：

- `Esc` 取消截图
- `Ctrl + Z` 撤销
- `Ctrl + C` 复制
- `Ctrl + S` 保存

## 提取文字（OCR）

基于 Windows 内置 OCR 引擎，支持从截图中提取文字。入口：

- 截图工具条中的 `T` 按钮
- 标注窗口工具栏
- 贴图窗口右键菜单
- 托盘菜单"提取剪贴板文字"

提取结果会弹出独立窗口，可直接复制。内置后处理优化：自动去除 CJK 字符间多余空格、修正常见误识别、规范标点。

## 贴图窗口

- 左键拖动图片可以移动位置。
- 双击图片可以关闭贴图。
- 右键图片会打开菜单，支持复制图片、保存为、切换置顶、提取文字、关闭贴图。
- `Ctrl + 滚轮` 可缩放贴图。

## 历史记录

主窗口下方显示最近 50 张截图缩略图。双击可重新打开标注窗口编辑，支持清空历史。

## 启动

```powershell
dotnet build .\src\PictureTool\PictureTool.csproj
dotnet run --project .\src\PictureTool\PictureTool.csproj
```

如果 `dotnet` 没有加入 PATH，可以使用完整路径：

```powershell
& "C:\Program Files\dotnet\dotnet.exe" build .\src\PictureTool\PictureTool.csproj
```

## 构建安装包

一键构建（需要安装 [Inno Setup 6](https://jrsoftware.org/isdl.php)）：

```powershell
.\build.ps1
```

仅发布不生成安装包：

```powershell
.\build.ps1 -SkipInstaller
```

生成的安装包位于 `publish\installer\PictureTool-Setup-1.0.0.exe`。
